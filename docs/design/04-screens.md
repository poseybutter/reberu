# 화면 명세

화면마다 **무엇을 보여 주고, 무엇을 할 수 있고, 무엇이 실시간으로 바뀌는지**를 적습니다. 이 문서가 도메인 모델과 API 목록의 재료가 되고, 그림(평면도·모바일·흐름)은 Claude Design이 이 문서를 보고 그립니다.

화면 방향은 [README의 화면 방향](README.md#화면-방향-확정)을 따릅니다. 업무 툴이 먼저이고, 공간(B1~B5)은 걸어 다니는 3D, 업무·관리 화면(C, D, E)은 공간 없는 2D입니다.

## 적는 방법

| 항목 | 뜻 |
| --- | --- |
| 목적 | 이 화면이 있는 이유 한 줄 |
| 상태 | 그려야 할 화면 상태. 상태마다 따로 그림 |
| 보이는 데이터 | 서버에서 받아야 하는 정보 |
| 행동 | 누를 수 있는 것 → 그 결과 |
| 실시간 | 새로고침 없이 바뀌어야 하는 것. [05-realtime.md](05-realtime.md)에서 모아 정리 |
| 빈·오류 | 데이터가 없거나 실패했을 때 보여 줄 것 |
| 이동 | 이 화면에서 갈 수 있는 화면 |

★는 모바일(390×844) 화면도 그리는 화면입니다. 예시 이름은 "다온", "하늘"처럼 지어낸 값만 씁니다.

## 큰 흐름

```
A1 로그인 ─┬─ 처음 ──────────▶ A2 가입 요청 ── 승인됨 ──▶ B1 로비
           ├─ 팀 하나 ────────▶ B1 로비
           └─ 팀 여러 개 ─────▶ A3 팀 고르기 ──▶ B1 로비

B1~B5 공간 ◀── 공간 목록·미니맵(B6) ──▶ 다른 공간
    │ 업무 패널·위쪽 막대
    ▼
C·D 업무 화면 ── 공간으로 돌아가기 ──▶ 마지막에 있던 공간

팀 관리자: 위쪽 막대 설정 ──▶ E1 ──▶ E2~E6
조직 관리자: 위쪽 막대 설정 ──▶ F1 ──▶ F2~F7, F2에서 팀 고르기 ──▶ 그 팀의 E1
```

## A. 들어오기

### A1 로그인 ★

- **목적**: Google 계정으로 들어옵니다.
- **상태**: 기본 / 로그인 실패 / 허용되지 않은 계정 / 정지된 계정
- **보이는 데이터**: 없음 (서비스 이름, 한 줄 소개는 고정 문구)
- **행동**
  - "Google로 시작하기" → Google 로그인 후 돌아옴
- **실시간**: 없음
- **빈·오류**
  - 로그인 실패: "로그인하지 못했어요. 다시 시도해 주세요."
  - 허용되지 않은 계정: "이 계정으로는 들어올 수 없어요." 허용 기준은 조직 설정(F7)에서 정합니다.
  - 정지된 계정: "계정이 정지됐어요. 조직 관리자에게 문의해 주세요."
- **이동**: 처음 → A2 / 팀 하나 → B1 / 팀 여러 개 → A3

### A2 가입 요청·승인 대기 ★

- **목적**: 팀에 가입을 요청하고 승인을 기다립니다. 초대 링크로 들어온다고 가정합니다(정하지 못한 점 #9).
- **상태**: 요청 전 / 대기 중 / 거절됨 / 승인됨
- **보이는 데이터**: 팀 이름, 요청 시각, 요청 상태, 거절이면 거절 시각
- **행동**
  - 요청 전: "가입 요청하기" → 대기 중으로 바뀜, 관리자에게 알림
  - 대기 중: "요청 취소" → 요청 전으로 돌아감
  - 거절됨: "다른 초대 링크로 요청하기" 안내
- **실시간**: 관리자가 승인·거절하면 바로 상태가 바뀜
- **빈·오류**
  - 초대 링크 없이 들어옴: "팀 관리자에게 초대 링크를 받아 주세요."
  - 만료되거나 잘못된 링크: "초대 링크를 쓸 수 없어요."
- **이동**: 승인됨 → B1

### A3 팀 고르기

- **목적**: 여러 팀에 속한 사람이 오늘 들어갈 팀을 고릅니다.
- **상태**: 기본
- **보이는 데이터**: 내가 활동 멤버인 팀 목록. 팀마다 이름, 직무 유형, 내 역할, 지금 접속자 수, 오늘 내 출석 여부, 안 읽은 알림 수. 보관된 팀은 아래에 따로 (보기만)
- **행동**
  - 팀 누르기 → 그 팀의 B1
- **실시간**: 없음. 팀별 접속자 수는 화면을 열 때 불러옴 ([05-realtime.md](05-realtime.md))
- **빈·오류**: 팀이 하나뿐이면 이 화면을 건너뜁니다. 팀이 없으면 A2 초대 링크 안내.
- **이동**: B1

## B. 공간 [모듈: 공간]

공간 모듈을 끈 팀은 B1~B6이 없고 B7 단순하게 보기가 첫 화면입니다(정하지 못한 점 #17). 출석은 공간과 관계없이 그 팀을 처음 연 순간 기록합니다([출석 규칙](03-progression.md#출석-규칙-고정)).

### B0 공통 요소

B1~B5 모든 공간 화면에 들어갑니다. B7 단순하게 보기에도 위쪽 막대와 업무 패널은 그대로 있습니다.

| 요소 | 내용 | 행동 |
| --- | --- | --- |
| 위쪽 막대 | 팀 이름, 현재 시각, 접속자 수, 내 레벨·EXP 막대, 알림(안 읽은 수), 보기 전환, 설정 | 팀 이름 → 팀 바꾸기(A3) / EXP 막대 → C5 / 알림 → D1 / 보기 전환 → B7 / 설정 → 내 설정·D2·팀 관리(E1, 팀 관리자)·조직 관리(F1, 조직 관리자) |
| 공간 목록 | 팀 공간(로비 / 내 자리 / 라운지 / 회의실 / 바닷가 / 산길)과 조직 공간(광장 / 연회장 / 공용 회의실) [모듈: 조직 공간]. 지금 있는 곳과 공간별 인원 "3/8", 연회장에서 모임 중이면 표시 | 누르면 그 공간으로 바로 이동 |
| 업무 패널 | 내 상태, 오늘 할 업무(오늘이 기간에 들어가는 내 업무, 최대 5개, 마감 지남·오늘 마감 표시), 오늘의 할 일, 오늘의 퀘스트 [모듈], 업무 화면 바로가기 | 상태 바꾸기, 업무 상태 바꾸기, 할 일 체크, "전체 보기" → C1·C3 |
| 공간 뷰 | 걸어 다니는 아바타(이름표 + 상태 표시), 소품, 자리 | 걷기, 아바타 누르기 → B8 |
| 행동 막대 | 공간별 행동 버튼. 자리·소품 가까이 가면 뜨는 버튼("앉기" 등) | 공간별 표 참고 |
| 잠깐 뜨는 알림 | 오른쪽 아래에 몇 초 떴다 사라짐 | 누르면 관련 화면 |
| 소리 | 기본 꺼짐. 위쪽 막대에 켜기/끄기 | |

- **보이는 데이터**: 내 프로필(이름, 아바타, 레벨, EXP), 안 읽은 알림 수, 공간별 인원과 정원, 지금 공간의 동료(위치, 상태, 이름표), 오늘 할 업무, 오늘의 퀘스트
- **실시간**: 접속자 수, 공간별 인원, 같은 공간 동료의 위치·입장·퇴장·상태, 안 읽은 알림 수, 잠깐 뜨는 알림, 내 EXP(다른 사람이 칭찬을 보냈을 때)
- **빈·오류**
  - 연결 끊김: 위쪽에 "다시 연결하는 중이에요" 띠. 공간 뷰는 멈추지만 업무 패널은 계속 씀
  - 공간 정원 참: 공간 목록에서 그 공간이 흐리게 보이고 "자리가 다 찼어요"
  - 3D를 그리지 못하는 기기: B7로 자동 전환하고 한 번 안내
- **입력 규칙**: 업무 패널이나 채팅 입력 칸에 글을 쓰는 동안에는 이동 키가 먹지 않습니다. 공간 뷰를 누른 뒤에만 이동합니다.

### B1 로비

- **목적**: 출근을 기록하고 동료와 인사합니다. 들어오면 처음 보는 공간입니다.
- **3D 세기**: 중
- **상태**: 오늘 첫 출근 / 이미 출근함 / 쉬는 날(주말·공휴일)
- **보이는 데이터**: 오늘 출석 시각, 연속 출석 일수, 이번 출석으로 받은 EXP, 로비에 있는 동료
- **오늘 요약** [모듈: 아침 요약]: 첫 출근 때 작은 카드로 보여 줌. 마감 지난 업무, 오늘 마감, 3일 안에 마감, 오늘 회의, 만료가 다가오는 인증 [모듈: 인증·만료일 관리]. 닫으면 업무 패널로 접힘
- **행동**
  - 들어오기 → 오늘 첫 출근이면 출석 장면(도장 찍힘, 연속 출석, 받은 EXP)을 보여 줌. 출석은 팀을 연 순간 이미 기록됨. 팀 전체에 "다온님이 출근했어요"
  - 쉬는 날에 들어오면 → "오늘은 쉬는 날이에요. 출석은 근무일에만 세요" 안내. 출근 알림을 보내지 않음
  - 인사하기 → 로비 동료에게 "다온님이 인사했어요"
  - 아바타 누르기 → B8
- **실시간**: 동료 출근 알림, 인사 알림, B0 공통 실시간
- **빈·오류**
  - 로비에 아무도 없음: "오늘 첫 번째로 왔어요"
  - 출석 기록 실패: "출석을 기록하지 못했어요" + 다시 시도. 공간 이용은 막지 않음
- **이동**: 공간 목록으로 B2~B5, B8

### B2 내 자리

- **목적**: 집중하러 가는 공간입니다. 오늘 할 일 요약은 업무 패널이 맡고, 내 자리는 책상과 집중을 맡습니다(정하지 못한 점 #3).
- **3D 세기**: 약
- **상태**: 할 일 있음 / 오늘 할 일 모두 끝남
- **보이는 데이터**: 내 책상과 소품(레벨로 연 것), 옆 책상의 동료와 상태, 오늘 할 업무 수와 끝낸 수
- **행동**
  - 책상에 앉기 → 상태를 "집중 중"으로 바꿀지 묻는 작은 버튼
  - 책상 꾸미기 → 연 소품 중 고르기 (C5와 같은 데이터)
  - 업무 패널의 행동은 B0와 같음
- **실시간**: 동료 상태 변화, B0 공통 실시간
- **빈·오류**
  - 오늘 할 업무 없음: "오늘 할 업무가 없어요" + "업무 추가" → C2
  - 모두 끝남: "오늘 할 일을 모두 끝냈어요" + 퇴근 요약 바로가기(C8)
- **이동**: C1, C2, C8

### B3 티타임 라운지

- **목적**: 차를 마시며 가볍게 이야기하고 칭찬을 보냅니다.
- **3D 세기**: 중
- **상태**: 기본 / 채팅 열림
- **보이는 데이터**: 테이블 둘레 의자와 앉은 동료, 라운지 채팅(오늘 것만)
- **행동**
  - 의자 가까이 → "앉기"
  - 찻주전자 가까이 → "차 마시기" → 라운지 동료에게 "다온님이 차를 마셔요"
  - 칭찬 보내기 [모듈: 칭찬] → B3-1
  - 채팅 → 라운지에 있는 사람끼리 짧은 메시지
  - 리액션 → 내 아바타 위에 짧은 반응이 떴다 사라짐
- **실시간**: 채팅, 리액션, 차 마시기 알림, B0 공통 실시간
- **빈·오류**
  - 라운지에 혼자: "동료가 오면 함께 차를 마실 수 있어요"
  - 채팅 전송 실패: 메시지 옆에 "다시 보내기"
- **이동**: B3-1, B8

### B3-1 칭찬 보내기 [모듈: 칭찬]

- **목적**: 동료에게 칭찬과 EXP를 보냅니다. B3과 B8에서 엽니다.
- **상태**: 작성 / 보냄
- **보이는 데이터**: 받는 사람 후보(팀 구성원, 나는 빼고), 받는 사람이 받을 EXP
- **행동**
  - 받는 사람 고르기, 짧은 메시지(최대 길이는 도메인 모델에서 정함) 쓰기
  - 보내기 → 받는 사람 EXP 지급, 받는 사람에게 알림, 창 닫힘
- **실시간**: 받는 사람 화면에 알림과 EXP 변화
- **빈·오류**
  - 나에게 보내기: 후보에 나오지 않음
  - 보내기 실패: 쓴 글을 지우지 않고 "보내지 못했어요"
  - 하루 상한(제안 #6)을 넘음: "오늘은 더 보낼 수 없어요"
- **이동**: 닫으면 연 화면으로

### B4 회의실

- **목적**: 회의 참석자가 모여 안건과 결과를 남깁니다. 음성·화상은 외부 링크로 엽니다.
- **3D 세기**: 약
- **상태**: 회의 전 / 회의 중 / 회의 끝(결과 요약)
- **보이는 데이터**: 회의 제목, 외부 회의 링크, 안건 목록, 공유 메모, 참석자(회의실에 들어온 사람), 회의 시작·끝 시각, 결과 요약
- **행동**
  - 들어가기 → 내 상태가 "회의 중"으로 바뀜, 참석자에 추가
  - 안건 적기 (회의 전·중)
  - 회의 시작 → 참석자에게 "회의가 시작됐어요"
  - 외부 회의 열기 → 링크를 새 창으로
  - 메모 쓰기 → 참석자 모두 같은 메모를 봄
  - 회의 끝내기 → 결과 요약 화면, 참석자에게 결과 공유, C7에 모임
  - 나가기 → 상태가 이전 상태로 돌아감
- **실시간**: 참석자 입장·퇴장, 회의 시작·끝, 안건과 메모 변경, B0 공통 실시간
- **빈·오류**
  - 열린 회의 없음: "지금 열린 회의가 없어요" + "회의 열기" (정하지 못한 점 #11)
  - 외부 링크 없음: "외부 회의 열기"를 흐리게
  - 메모 저장 실패: "저장하지 못했어요"와 내가 쓴 글 유지
- **이동**: 회의 끝 → 결과 요약, C7

### B5 힐링 존: 바닷가

- **목적**: 일하다 쉬러 오는 곳입니다. 모닥불에서 불멍, 파도 앞이나 파라솔에서 물멍, 요가 매트에서 짧은 요가를 합니다. 쉰 횟수가 쌓이고 업적이 열립니다.
- **3D 세기**: 강
- **상태**: 둘러보기 / 쉬는 중(불멍·물멍·요가) / 쉬기 끝. 시간대: 낮 / 노을 / 밤. 날씨: 맑음 / 구름 조금 / 흐림 / 비 / 바람 / 안개 / 눈 / 무지개 ([02-spaces.md의 날씨](02-spaces.md#날씨))
- **보이는 데이터**: 지금 날씨, 모닥불과 통나무 의자, 파도 앞 돗자리, 파라솔과 비치 의자, 요가 매트와 동작 버튼, 각 자리에 앉은 동료, 휴식 타이머, 내 누적 휴식 횟수(불멍·물멍 따로), 다음 업적까지 남은 횟수, 멍하는 동안 모아 둔 알림 수
- **행동**
  - 자리 가까이 → "앉기"
  - 멍하기 시작 → 타이머 시작, 카메라가 불·바다 쪽으로 천천히 다가감, 업무 패널과 위쪽 막대가 접혀 가장자리에 작게 남음
  - 장작 넣기 (모닥불에 앉았을 때) → 둘레 사람에게 짧은 알림, 둘레 인원에 따라 불 크기 변화
  - 요가 동작 고르기 (요가 매트에서) → 아바타가 그 동작을 천천히 함, 옆 매트 사람에게도 보임
  - 업무 패널 펼치기 → 멍하기는 이어지고 패널만 다시 보임
  - 멍하기 끝 → 휴식 횟수 +1, 모아 둔 알림을 한 번에 보여 줌, 기준을 넘으면 업적이 열렸다는 짧은 알림
- **실시간**: 동료 위치와 앉은 자리, 장작 넣기, 모닥불 둘레 인원, 요가 동작, 날씨 변화, B0 공통 실시간. 멍하는 동안 알림은 화면에 띄우지 않고 모음(제안 #5)
- **빈·오류**
  - 타이머 중 연결 끊김: 다시 연결되면 시작 시각 기준으로 이어서 계산
  - 너무 짧은 휴식(기준은 도메인 모델에서 정함): 횟수에 넣지 않고 "조금 더 쉬어도 돼요"
- **이동**: C5 업적

### B12 힐링 존: 산길

- **목적**: 순례길처럼 천천히 걸으며 쉬는 곳입니다. 걷멍, 계곡 물멍, 정상 산멍을 하고 팀이 함께 걸은 거리를 쌓습니다.
- **3D 세기**: 강
- **상태**: 둘러보기 / 걷는 중(직접·자동) / 쉬는 중(물멍·산멍) / 걷기 끝. 시간대: 낮 / 노을 / 밤. 계절: 봄 / 여름 / 가을 / 겨울. 날씨: 바닷가와 같음
- **보이는 데이터**: 길과 구간(숲 입구, 숲길, 계곡, 오르막 쉼터, 정상 전망대, 내려오는 길), 길 위의 동료, 내 위치와 이번에 받은 구간 도장, 걸은 거리와 시간, 팀이 오늘·이번 시즌 함께 걸은 거리와 다음 풍경까지 남은 거리, 쉼터의 돌탑(남긴 말), 모아 둔 알림 수
- **행동**
  - 걷기, 천천히 걷기(자동) → 업무 패널과 위쪽 막대가 접힘, 아무 키나 누르면 멈춤
  - 쉬는 곳 가까이 → "앉기", 물멍·산멍 시작
  - 오르막 쉼터에서 말 남기기 → 돌탑이 하나 쌓임, 같은 팀이 읽음
  - 돌탑 누르기 → 남긴 말 읽기
  - 걷기 끝 → 걸은 거리·시간을 휴식으로 셈, 한 바퀴를 다 돌았으면 "한 바퀴 완주"
- **실시간**: 길 위 동료의 위치(자동으로 걸을 때는 구간과 진행 정도만), 인사, 새 돌탑, 팀이 함께 걸은 거리, 날씨 변화, B0 공통 실시간
- **빈·오류**
  - 길에 아무도 없음: "오늘 첫 번째로 길을 걸어요"
  - 말 남기기 실패: 쓴 글 유지
  - 연결 끊김: 다시 연결되면 마지막 구간에서 이어 걸음
- **이동**: B5 (길로 이어짐), C5 업적

### B6 미니맵

- **목적**: 공간 다섯 곳의 배치와 인원을 한눈에 보고 바로 옮깁니다. 공간 위에 뜨는 창입니다.
- **상태**: 기본
- **보이는 데이터**: 공간별 이름, 인원/정원, 회의 중 여부, 내가 있는 곳
- **행동**
  - 공간 누르기 → 그 공간으로 바로 이동
- **실시간**: 공간별 인원, 회의 시작·끝
- **빈·오류**: 정원이 찬 공간은 누를 수 없음
- **이동**: B1~B5

### B7 단순하게 보기 ★

- **목적**: 공간 그림 없이 동료와 상태만 보는 화면입니다. 3D가 부담스럽거나 기기가 느린 사람도 모든 기능을 씁니다.
- **상태**: 기본
- **보이는 데이터**: 동료 목록(이름, 상태, 지금 있는 공간), 업무 패널
- **행동**
  - 공간 고르기 → 그 공간에 있는 것으로 기록 (그림 없이). 출석·회의 중 상태 규칙은 B1~B5와 같음
  - 동료 누르기 → B8 (인사, 부르기, 칭찬)
  - 공간별 행동(차 마시기, 휴식 시작 등)은 버튼 목록으로
  - 보기 전환 → 공간 화면
- **실시간**: 동료 상태와 위치(공간 단위), 알림
- **빈·오류**: 접속한 동료 없음: "지금 접속한 동료가 없어요"
- **이동**: B8, C, D

### B8 동료 카드

- **목적**: 동료 한 명의 정보를 보고 짧게 말을 겁니다. 아바타나 동료 목록을 누르면 뜹니다.
- **상태**: 기본 / 동료가 집중 중·회의 중 / 다른 팀 사람(조직 공간에서)
- **보이는 데이터**: 이름, 아바타, 상태, 레벨, 지금 있는 공간. 다른 팀 사람이면 이름, 팀, 상태만 (레벨·칭찬은 팀 기록이라 보이지 않음)
- **행동**
  - 손 흔들어 부르기 → 상대에게 "다온님이 부르고 있어요"
  - 칭찬 보내기 → B3-1 (받는 사람이 채워진 상태)
- **실시간**: 상대 상태 변화
- **빈·오류**
  - 상대가 집중 중·회의 중: 부르기 버튼 옆에 "지금 집중 중이에요" 안내. 막지는 않음
  - 상대가 나감: "지금 접속해 있지 않아요"
- **이동**: B3-1

### 조직 공간 [모듈: 조직 공간]

조직 전체가 함께 들어오는 공간입니다. 조직 관리자가 F4에서 켜는 조직 단위 모듈입니다. 규칙은 [02-spaces.md의 조직 공간](02-spaces.md#조직-공간-모듈-조직-공간)을 따릅니다. 업무 패널은 계속 지금 보고 있는 팀의 것입니다.

### B9 광장

- **목적**: 다른 팀 사람과 오가며 만나고, 연회장과 공용 회의실로 들어갑니다.
- **3D 세기**: 중
- **상태**: 기본 / 연회장에서 모임 중
- **보이는 데이터**: 광장에 있는 사람(가까운 사람 위주), 연회장 모임 일정과 진행 여부, 공용 회의실 목록과 지금 열린 회의
- **행동**
  - 걷기, 인사하기, 리액션 → 가까이 있는 사람에게 보임
  - 아바타 누르기 → B8 (다른 팀 사람이면 이름·팀·상태만)
  - 입구 가까이 → "들어가기" → B10, B11
- **실시간**: 가까운 사람의 위치, 광장 입장·퇴장, 연회장 모임 시작·끝
- **빈·오류**: 광장에 아무도 없음: "아직 아무도 없어요. 연회장 일정을 확인해 보세요"
- **이동**: B10, B11, 팀 공간

### B10 연회장

- **목적**: 조직 전체 모임(타운홀 미팅, 시즌 시상, 새 구성원 환영)을 합니다.
- **3D 세기**: 중
- **상태**: 모임 없음(둘러보기) / 모임 전(입장 중) / 모임 중 / 모임 끝(요약)
- **배치**: 팀마다 긴 테이블 하나, 앞쪽에 단상. 들어가면 내 팀 테이블 빈자리에 앉음 ([02-spaces.md](02-spaces.md#연회장-b10))
- **보이는 데이터**
  - 모임: 제목, 일시, 진행자, 발표자, 안건 순서와 지금 안건, 외부 회의 링크
  - 테이블: 팀별 테이블과 앉은 사람 수, 내 팀 테이블의 사람
  - 질문 목록: 질문, "나도 궁금해요" 수, 답함 여부, 쓴 사람(이름 숨김이면 "익명")
  - 손든 사람 목록 (진행자에게만)
- **행동**
  - 구성원: 앉기, 자리 옮기기, 손들기, 질문 남기기, "나도 궁금해요", 리액션, 외부 회의 열기
  - 진행자: 모임 시작, 안건 넘기기, 발표자를 단상으로 부르기·내리기, 질문 "답함" 표시, 건배, 모임 끝내기
- **실시간**: 지금 안건, 단상에 선 사람, 질문 추가와 "나도 궁금해요" 수, 손든 사람(진행자), 묶은 리액션 수, 테이블별 인원, 모임 시작·끝
- **빈·오류**
  - 모임 없음: 둘러보기만. "다음 모임: 11월 28일 16:00"
  - 연회장 정원 참: "자리가 다 찼어요" + 단순하게 보기로 참여(안건·질문만 보임)
  - 질문 저장 실패: 쓴 글 유지
- **이동**: 모임 끝 → 요약, B9

### B11 공용 회의실

- **목적**: 여러 팀이 함께하는 회의를 합니다.
- **3D 세기**: 약
- **상태**: B4와 같음 (회의 전 / 회의 중 / 회의 끝)
- **보이는 데이터**: B4와 같고, 참석자마다 팀이 함께 보임
- **행동**
  - 회의 열기 → 제목, 외부 링크, 참석자를 여러 팀에서 고름. 조직의 활동 계정이면 누구나 열 수 있음
  - 그 밖의 행동은 B4와 같음
  - 회의에서 나온 할 일 → "내 팀 업무로 만들기" → 내 팀의 C2 (다른 팀 업무는 만들지 않음)
- **실시간**: B4와 같음
- **빈·오류**: 초대받지 않은 회의: "초대받은 사람만 들어올 수 있어요"
- **이동**: C2 (내 팀), B9

## C. 업무와 성장

### C0 공통 틀

C, D 화면은 공간 없는 2D 화면입니다.

- 위쪽 막대는 B0과 같고, 공간 목록 대신 **"공간으로 돌아가기"**가 있습니다. 누르면 마지막에 있던 공간으로 돌아갑니다.
- 업무 화면을 보는 동안에도 공간에는 그대로 있는 것으로 봅니다. 동료에게는 내 아바타가 그 자리에 보입니다.
- 왼쪽 메뉴: 업무, 프로젝트, 오늘의 할 일, 리포트, 프로필, 명예의 전당 [모듈], 알림, 그리고 켠 모듈의 메뉴. 끈 모듈의 메뉴는 보이지 않습니다.

### 업무 규칙 (C1, C2 공통)

| 항목 | 내용 |
| --- | --- |
| 상태 | 할 일 / 진행 중 / 보류 / 완료. 정해진 순서 없이 아무 상태로나 바꿈. 새 업무는 "할 일" |
| 우선순위 | 긴급 / 높음 / 보통 / 낮음. 기본 "보통" |
| 기간 | 시작일~마감일. 하루만 고르면 그날이 마감일 |
| 프로젝트 | 업무는 반드시 프로젝트 하나에 속함. 보관된 프로젝트는 고를 수 없음 |
| 세부 항목 | 업무 하나에 여러 줄. 줄마다 내용, 공수(30분·1시간·2시간·4시간·1일·2일 또는 직접 입력), 완료 여부. 순서를 바꿀 수 있음 |
| 표시 | 중요 표시(오늘 요약·업무 패널에서 강조), 리포트에 넣기 |
| 권한 | 관리자는 누구에게나 배정하고 모든 업무를 고침. 구성원은 담당자로 자기만 고르고 자기 업무만 고침. 읽기 전용은 보기만 |
| EXP | 완료하면 담당자에게 우선순위에 따라 지급([03-progression.md](03-progression.md)). 완료를 풀면 돌려받음(정하지 못한 점 #19) |

### C1 업무 목록 ★

- **목적**: 내 업무와 팀 업무를 보고 상태를 바꿉니다.
- **상태**: 내 업무 탭 / 팀 업무 탭. 묶는 방식: 상태별 / 담당자별
- **보이는 데이터**: 업무마다 제목, 담당자, 프로젝트, 우선순위, 기간, 상태, 중요 표시, 세부 항목 진행(3/5), 공수 합계. 묶음마다 건수와 공수 합계. 완료는 접어 둠
- **행동**
  - 탭 바꾸기, 묶는 방식 바꾸기
  - 필터: 담당자, 프로젝트(검색), 우선순위, 상태
  - 업무 상태 바꾸기 → 완료로 바꾸면 담당자에게 EXP
  - 업무 누르기 → C2
  - 새 업무 → C2 작성 (읽기 전용은 버튼 없음)
- **실시간**: 팀 업무 탭에서 다른 사람이 만든·바꾼 업무
- **빈·오류**
  - 업무 없음: "아직 업무가 없어요" + "새 업무"
  - 필터 결과 없음: "조건에 맞는 업무가 없어요"
  - 프로젝트가 하나도 없음: "먼저 프로젝트를 만들어 주세요" + C10 (팀 관리자만)
- **이동**: C2, C10

### C2 업무 상세·작성

- **목적**: 업무 하나를 만들고 고칩니다.
- **상태**: 작성 / 보기 / 수정 / 완료됨 / 고칠 권한 없음(보기만)
- **보이는 데이터**: 제목, 설명(서식 있는 글), 담당자, 프로젝트, 우선순위, 기간, 상태, 세부 항목, 중요 표시, 리포트에 넣기, 만든 사람, 만든·바꾼 시각
- **행동**
  - 저장 → 업무 만들기·고치기, 담당자가 바뀌면 새 담당자에게 알림
  - 세부 항목 추가·고치기·순서 바꾸기·체크
  - 완료 → 담당자에게 EXP
  - 다시 열기 → 상태가 돌아가고 EXP도 돌려받음
  - 지우기 → 확인 후 지움, 활동 기록에 남김
- **실시간**: 보고 있는 업무를 다른 사람이 바꾸면 "하늘님이 이 업무를 바꿨어요" + 새로 불러오기
- **빈·오류**
  - 제목·프로젝트·기간 없음: 저장 안 됨, 칸 아래 안내
  - 없는 업무: "업무를 찾을 수 없어요"
  - 권한 없음: 고치기 버튼을 숨기고 보기만
  - 저장 실패: 쓴 글 유지
- **이동**: C1, C10

### C3 오늘의 할 일·퀘스트 ★

- **목적**: 오늘 하루의 작은 일을 적고 체크합니다. 업무 패널에 요약이 있고, 여기서 전체를 봅니다.
- **상태**: 진행 중 / 모두 끝남
- **보이는 데이터**
  - 오늘의 할 일: 내가 적은 목록, 완료 여부. 어제 못 끝낸 것은 위에 따로 보여 줌
  - 오늘의 퀘스트 [모듈]: 서버가 준 3개, 퀘스트마다 EXP와 완료 여부, 모두 끝냈을 때 보너스
- **행동**
  - 할 일 추가·고치기·지우기·끌어서 순서 바꾸기
  - 할 일 체크 → 작은 EXP. 하루 상한까지 / 체크 풀기 → 돌려받음
  - 어제 것 "오늘로 가져오기"
  - 퀘스트는 행동하면 자동으로 체크됨 (정하지 못한 점 #1, #2)
- **실시간**: 자동 체크된 퀘스트의 완료 표시
- **빈·오류**
  - 할 일 없음: "오늘 할 일을 적어 볼까요?"
  - 퀘스트를 아직 못 받음: "퀘스트를 준비하고 있어요"
- **이동**: 없음

### C4 레벨업

- **목적**: 레벨이 오른 것을 알리되 하던 일을 막지 않습니다.
- **상태**: 짧은 알림 / 축하 창
- **보이는 데이터**: 새 레벨, 새로 열린 것(꾸미기, 소품, 공간)
- **행동**
  - 짧은 알림 누르기 → 축하 창
  - 축하 창의 "꾸미러 가기" → C5
- **실시간**: 내 레벨 변화, 같은 공간 동료에게 "다온님이 Lv.5가 됐어요"
- **빈·오류**: 새로 열린 것이 없으면 새 레벨만 보여 줌
- **이동**: C5

### C5 프로필 ★

- **목적**: 내 성장 기록을 보고 아바타·책상을 꾸밉니다.
- **상태**: 기본 / 꾸미기
- **보이는 데이터**: 아바타와 꾸미기, 레벨·칭호와 누적 EXP, 다음 레벨까지 남은 EXP, 출석 도장판(근무일마다 도장, 주말·공휴일은 흐리게, 연속 출석), 받은 칭찬 수 [모듈: 칭찬], 업적(연 것과 아직인 것), 최근 EXP 내역, 지난 업무(이번 주·지난주·이번 달·기간 지정)
- **행동**
  - 꾸미기 → 연 것 중에서 고르기, 저장하면 공간의 내 아바타·책상에 반영
- **실시간**: 없음
- **빈·오류**: 업적 없음: "첫 업적까지 출석 1회 남았어요"
- **이동**: C6

### C6 명예의 전당 [모듈]

- **목적**: 팀의 이번 시즌 기록을 함께 봅니다.
- **상태**: 이번 시즌 / 지난 시즌
- **보이는 데이터**: 시즌 EXP 순위, 연속 출석 순위, 칭찬 많이 받은 순위 [모듈: 칭찬], 내 순위, 지난 시즌 기록. 시즌 규칙은 [03-progression.md](03-progression.md)
- **행동**: 순위 종류 바꾸기
- **실시간**: 없음 (들어올 때 불러옴)
- **빈·오류**: 이번 시즌 기록 없음: "이번 시즌 첫 기록을 남겨 보세요"
- **이동**: 없음

### C7 리포트

- **목적**: 팀의 한 주를 한 장으로 보고, 팀에 전할 말을 함께 적습니다.
- **상태**: 이번 주(편집 가능) / 마감 지남(보기만) / 지난주들. 주 단위 / 월 단위
- **보이는 데이터**
  - 업무: "리포트에 넣기"한 업무와 이번 주 완료 업무를 상태별·담당자별·프로젝트별로 묶어 봄
  - 담당 현황: 담당자가 정해진 업무와 아직 안 정해진 업무
  - 공지 칸: 확인해 주세요, 이번 목표, 전달 사항. 이번 주에 쓴 것이 없으면 지난주 것을 이어서 보여 줌
  - 출석률, 회의 요약 (B4 결과)
  - 주의 시작 요일과 편집 마감 시각은 팀 설정 값 (정하지 못한 점 #20)
- **행동**
  - 주·월 바꾸기, 묶는 방식 바꾸기
  - 공지 칸 쓰기 (마감 전까지)
  - 전체 복사 → 리포트를 글로 복사해 다른 곳에 붙여 넣기
- **실시간**: 다른 사람이 공지 칸이나 업무를 바꾸면 반영
- **빈·오류**
  - 기록 없는 주: "이 주에는 기록이 없어요"
  - 마감 지남: 편집 칸을 잠그고 "이번 주 리포트가 마감됐어요"
- **이동**: C2, 회의 결과

### C8 퇴근 요약 ★

- **목적**: 오늘 한 일을 보고 하루를 마칩니다.
- **상태**: 기본 / 퇴근함
- **보이는 데이터**: 오늘 출석 시각, 완료한 업무, 받은 EXP, 휴식 횟수와 시간, 받은 칭찬
- **행동**
  - "내일 봐요" → 퇴근 시각 기록, 공간에서 나감 (정하지 못한 점 #10)
- **실시간**: 없음
- **빈·오류**: 오늘 완료한 업무 없음: "오늘은 쉬어 가는 날이었어요"
- **이동**: A1 또는 로그아웃 화면

### C9 프로젝트 목록

- **목적**: 팀의 프로젝트를 찾고 관리합니다.
- **상태**: 진행 중 / 보관함
- **보이는 데이터**: 프로젝트마다 이름, 대표 담당자, 구성원 수, 진행 중 업무 수, 마감 지난 업무 수. 보관함 개수
- **행동**
  - 검색, "내 프로젝트만" 거르기
  - 프로젝트 누르기 → C10
  - 새 프로젝트 → C10 작성 (팀 관리자만)
  - 보관·복원 (팀 관리자만)
- **실시간**: 없음 (들어올 때 불러옴)
- **빈·오류**
  - 프로젝트 없음: 관리자 "첫 프로젝트를 만들어 주세요" / 구성원 "아직 프로젝트가 없어요"
- **이동**: C10

### C10 프로젝트 상세·작성

- **목적**: 프로젝트 하나의 정보와 업무를 봅니다.
- **상태**: 작성 / 보기 / 수정 / 보관됨(보기만)
- **보이는 데이터**: 이름, 설명, 대표 담당자, 구성원, 기간(선택), 이 프로젝트의 업무(C1과 같은 묶음), 팀이 정한 추가 항목
- **행동**
  - 저장 (팀 관리자만)
  - 구성원 추가·빼기, 대표 담당자 정하기 → "내 프로젝트" 거르기와 업무 담당자 후보에 쓰임
  - 추가 항목 넣기: 글, 메모 종류로 항목을 직접 더하고 순서를 바꿈. 비밀 정보는 넣지 않음 (정하지 못한 점 #18)
  - 이 프로젝트에 새 업무 → C2 (프로젝트가 채워진 상태)
- **실시간**: 없음
- **빈·오류**
  - 이름 없음: 저장 안 됨
  - 보관된 프로젝트: 새 업무 버튼을 숨기고 "보관된 프로젝트예요"
- **이동**: C2, C9

## D. 알림

### D1 알림 목록

- **목적**: 놓친 알림을 모아 봅니다. 위쪽 막대 알림을 누르면 뜹니다.
- **상태**: 전체 / 안 읽음
- **보이는 데이터**: 알림마다 종류(업무 배정, 업무 마감 임박, 업무 마감 지남, 회의 시작, 레벨업, 연회장 모임 일정·시작·공용 회의 초대 [모듈: 조직 공간], 출근·인사·부르기 [모듈: 공간], 칭찬 [모듈: 칭찬], 인증 만료 임박 [모듈: 인증·만료일 관리]), 보낸 사람, 시각, 읽음 여부
- **행동**
  - 알림 누르기 → 읽음 처리, 관련 화면으로
  - 모두 읽음
- **실시간**: 새 알림이 맨 위에 추가
- **빈·오류**: 알림 없음: "새 알림이 없어요"
- **이동**: 알림마다 관련 화면 (칭찬 → C5, 업무 배정 → C2, 회의 시작 → B4)

### D2 알림 설정

- **목적**: 받을 알림을 고릅니다. 방해받지 않을 권리를 지킵니다.
- **상태**: 기본
- **보이는 데이터**: 알림 종류별 켜기/끄기, 방해 금지 시간
- **행동**: 켜고 끄기, 방해 금지 시간 정하기 → 바로 저장
- **실시간**: 없음
- **빈·오류**: 저장 실패: 바꾸기 전 값으로 되돌리고 안내
- **이동**: 없음

## E. 팀 관리자

팀 관리자와 조직 관리자만 엽니다. 구성원이 주소로 열면 "이 화면은 팀 관리자만 볼 수 있어요"를 보여 줍니다. 모두 평범한 관리 화면이고, 지금 보고 있는 팀 하나만 다룹니다.

### E1 관리자 첫 화면

- **목적**: 오늘 팀 상황과 처리할 일을 봅니다.
- **보이는 데이터**: 승인 대기 수, 오늘 출석한 사람과 안 한 사람 수(쉬는 날이면 "오늘은 쉬는 날"), 최근 활동 기록 5개
- **행동**: 각 숫자 누르기 → E2, E3, E5
- **실시간**: 승인 대기 수, 오늘 출석 수
- **빈·오류**: 대기 없음: "처리할 요청이 없어요"
- **이동**: E2~E6

### E2 가입 요청 관리

- **목적**: 가입 요청을 승인하거나 거절합니다.
- **상태**: 대기 / 처리됨
- **보이는 데이터**: 요청한 사람 이름·이메일, 요청 시각, 처리한 사람과 시각
- **행동**
  - 승인 → 요청한 사람 화면이 B1로 넘어감
  - 거절 → 요청한 사람 화면이 A2 거절됨으로 바뀜
  - 초대 링크 만들기·복사·끄기
  - 바로 추가 → 조직 계정을 검색해 역할을 정하고 요청 없이 추가
- **실시간**: 새 요청 추가
- **빈·오류**: 다른 관리자가 먼저 처리함: "이미 처리된 요청이에요"
- **이동**: 없음

### E3 구성원 관리

- **목적**: 구성원의 역할을 바꾸거나 내보냅니다.
- **보이는 데이터**: 구성원 이름, 이메일, 역할(관리자 / 구성원 / 읽기 전용), 상태(활동 / 정지), 가입일, 최근 출석일
- **행동**
  - 역할 바꾸기
  - 정지·해제 → 정지된 사람은 이 팀에 들어올 수 없음, 기록은 남음
  - 팀에서 내보내기 → 확인 후 처리, 그 사람은 이 팀 공간에서 나감
- **실시간**: 없음
- **빈·오류**: 마지막 관리자를 구성원으로 바꾸거나 내보내기: 막고 "관리자가 한 명은 있어야 해요"
- **이동**: E5 (그 사람의 기록)

### E4 팀 설정·역할

- **목적**: 팀 설정을 고치고 역할별 권한을 봅니다. 팀 만들기는 조직 관리자의 F2에서 합니다.
- **상태**: 기본
- **보이는 데이터**: 팀 이름, 직무 유형(만들 때 고른 것, 보기만), 업무 구분 라벨, 업무·프로젝트 추가 항목, 리포트 공지 칸 제목, 리포트 주의 시작 요일과 편집 마감 시각, 공간별 정원 [모듈: 공간], 역할과 권한 표
- **행동**: 팀 설정 저장, 라벨·추가 항목 더하기·고치기·순서 바꾸기, 역할 권한 보기
- **실시간**: 없음
- **빈·오류**: 저장 실패: 바꾸기 전 값 유지
- **이동**: 없음

### E5 활동 기록

- **목적**: 누가 언제 무엇을 바꿨는지 찾아봅니다.
- **보이는 데이터**: 시각, 한 사람, 한 일(가입 승인, 역할 변경, 업무 수정 등), 대상
- **행동**: 기간·사람·종류로 거르기
- **실시간**: 없음
- **빈·오류**: 결과 없음: "조건에 맞는 기록이 없어요"
- **이동**: 없음

### E6 팀 기능

- **목적**: 이 팀에서 쓸 기능 모듈을 켜고 끕니다. 고정 기능은 이 목록에 나오지 않습니다.
- **상태**: 기본 / 끄기 확인
- **보이는 데이터**: 조직이 허용한(F4) 모듈만 보임. 모듈마다 이름, 한 줄 설명, 켜짐 여부, 켜면 생기는 메뉴·화면, 필요한 모듈. reberu 모듈(공간, 오늘의 퀘스트, 칭찬, 명예의 전당, 아침 요약, 인증·만료일 관리)과 복사한 조직이 더한 조직 모듈이 같은 목록에 보임
- **행동**
  - 켜기 → 그 팀 구성원 화면에 메뉴와 화면이 바로 생김
  - 끄기 → "쌓인 기록은 남고 다시 켜면 이어져요" 확인 후 끔. 메뉴, 화면, 알림, EXP 출처가 바로 사라짐
  - 모든 변경은 활동 기록(E5)에 남음
- **실시간**: 켜고 끄면 지금 접속한 구성원 화면에 바로 반영
- **빈·오류**: 저장 실패: 바꾸기 전 상태로 되돌리고 안내
- **이동**: 모듈마다 설정이 있으면 그 설정 화면

## F. 조직 관리자

조직 관리자만 엽니다. 팀을 넘어 조직 전체를 다루는 평범한 관리 화면입니다. 조직 관리자는 F2에서 어느 팀이든 골라 그 팀의 E 화면을 열 수 있습니다.

### F1 조직 첫 화면

- **목적**: 조직 전체 상황을 봅니다.
- **보이는 데이터**: 팀 수와 팀별 인원, 팀별 승인 대기 수, 팀별 오늘 출석 수, 최근 조직 활동 기록 5개
- **행동**: 숫자 누르기 → F2, F5, F6, 팀별 E 화면
- **실시간**: 없음 (들어올 때 불러옴)
- **빈·오류**: 팀 없음: "첫 팀을 만들어 주세요" + F2
- **이동**: F2~F7

### F2 팀 목록·만들기

- **목적**: 팀을 만들고 보관합니다.
- **상태**: 진행 중 / 보관함 / 팀 만들기
- **보이는 데이터**: 팀마다 이름, 직무 유형, 인원, 팀 관리자, 켠 모듈 수, 만든 날
- **행동**
  - 팀 만들기 → 이름, 직무 유형, 첫 팀 관리자 고르기. 직무 유형의 기본값이 팀에 복사됨
  - 보관·복원
  - 팀 누르기 → 그 팀의 E1
- **빈·오류**
  - 같은 이름의 팀: "이미 있는 팀 이름이에요"
  - 첫 팀 관리자 없음: 만들 수 없음
- **이동**: E1 (고른 팀)

### F3 직무 유형

- **목적**: 팀을 만들 때 고를 직무 유형과 그 기본값을 관리합니다.
- **보이는 데이터**: 직무 유형마다 이름, 설명, 켤 모듈, 업무 구분 라벨, 업무·프로젝트 추가 항목, 리포트 공지 칸, 리포트 주기 기본값, 이 유형으로 만든 팀 수
- **행동**: 직무 유형 더하기·고치기·숨기기. 고쳐도 이미 만든 팀은 바뀌지 않는다는 안내
- **빈·오류**: 쓰는 팀이 있는 유형은 지우지 않고 숨기기만
- **이동**: 없음

### F4 허용 모듈

- **목적**: 이 조직의 팀들이 켤 수 있는 모듈을 정합니다.
- **보이는 데이터**: 설치된 모듈 목록(reberu 모듈 + 조직 모듈), 모듈마다 허용 여부, 켠 팀 수
- **행동**
  - 허용 → 팀 기능(E6)에 나타남
  - 허용 거두기 → "켠 팀 3곳에서 꺼져요. 기록은 남아요" 확인 후 거둠
- **실시간**: 거두면 그 모듈을 켠 팀들에 `team.modules-changed`
- **빈·오류**: 저장 실패: 바꾸기 전 상태 유지
- **이동**: 없음

### F5 계정 관리

- **목적**: 조직의 계정을 보고 정지하거나 조직 관리자를 정합니다.
- **보이는 데이터**: 계정마다 이름, 이메일, 계정 상태, 조직 관리자 여부, 속한 팀과 팀 역할, 마지막 접속
- **행동**
  - 정지·해제 → 정지되면 모든 팀에서 바로 나가짐
  - 조직 관리자 지정·해제
  - 팀에 바로 추가 → 팀과 역할 고르기
- **빈·오류**: 마지막 조직 관리자 해제: 막고 "조직 관리자가 한 명은 있어야 해요"
- **이동**: 팀별 E3

### F6 조직 활동 기록

- **목적**: 조직 변경과 모든 팀의 활동 기록을 찾아봅니다.
- **보이는 데이터**: 시각, 한 사람, 한 일, 대상, 팀(팀 기록이면)
- **행동**: 기간·사람·종류·팀으로 거르기
- **빈·오류**: 결과 없음: "조건에 맞는 기록이 없어요"
- **이동**: 없음

### F7 조직 설정

- **목적**: 조직 이름, 시간대, 로그인 허용 기준을 정합니다.
- **보이는 데이터**: 조직 이름, 시간대(출석의 하루 경계인 자정의 기준), 로그인 허용 기준(허용 이메일 도메인 목록)
- **행동**: 저장. 허용 기준을 바꿔도 이미 들어온 계정은 그대로이고, 막으려면 F5에서 정지
- **빈·오류**: 허용 기준이 비면 저장하지 않음: "허용할 도메인을 하나 이상 넣어 주세요"
- **이동**: F8

### F8 휴일 달력

- **목적**: 출석에서 뺄 공휴일과 조직 휴일을 정합니다. 주말은 넣지 않아도 늘 쉬는 날입니다.
- **상태**: 연도별 달력 / 목록
- **보이는 데이터**: 휴일마다 날짜, 이름(예: "창립 기념일"), 넣은 사람
- **행동**
  - 휴일 더하기·고치기·지우기
  - 다른 해의 휴일을 복사해 와서 날짜만 고치기
- **실시간**: 없음
- **빈·오류**
  - 다음 해 휴일이 비어 있음: 연말에 F1에 "내년 휴일을 넣어 주세요" 안내
  - 지난 날짜를 고침: "이미 남은 출석 기록은 바뀌지 않고, 연속 출석만 다시 세요" 확인
- **이동**: 없음

### F9 연회장 모임 [모듈: 조직 공간]

- **목적**: 연회장 전체 모임을 미리 잡고 지난 모임 기록을 봅니다.
- **상태**: 다가오는 모임 / 지난 모임
- **보이는 데이터**: 모임마다 제목, 일시, 진행자, 발표자, 안건, 외부 회의 링크. 지난 모임은 요약(안건, 답한 질문, 남은 질문), 참석 인원
- **행동**
  - 모임 만들기·고치기·취소 → 조직 전체에 일정 알림
  - 진행자 정하기 (조직 관리자가 아닌 사람도 지정 가능)
  - 연회장 정원 정하기
- **실시간**: 없음
- **빈·오류**: 다가오는 모임 없음: "아직 잡힌 모임이 없어요"
- **이동**: B10
