# 사용자의 하루 흐름

## 처음 한 번

1. Google 계정으로 로그인합니다. ⟶ A1
2. 처음이면 팀에 가입 요청을 하고 관리자 승인을 기다립니다. ⟶ A2
3. 승인되면 로비로 들어갑니다. ⟶ B1
4. 여러 팀에 속해 있으면 들어갈 팀을 고릅니다. ⟶ A3

## 하루

| 순서 | 하는 일 | 화면 | EXP |
| --- | --- | --- | --- |
| 1 | 로그인하면 **로비**에 들어옵니다. 그날 그 팀을 처음 연 순간 출석이 기록되고(근무일만, [출석 규칙](03-progression.md#출석-규칙-고정)), 연속 출석 일수와 오늘 요약(마감 지난 업무, 오늘 마감, 오늘 회의)이 보입니다 | B1 | 출석, 연속 출석 |
| 2 | 먼저 와 있던 동료에게 인사합니다 | B1 | |
| 3 | **내 자리**로 가서 오늘의 할 일을 적고, 업무와 퀘스트를 확인하고, 상태를 "집중 중"으로 바꿉니다 | B2, C3 | |
| 4 | 업무를 완료합니다. 레벨이 오르면 축하 알림이 뜹니다 | C1, C2, C4 | 업무 완료 |
| 5 | 퀘스트를 체크합니다. 모두 끝내면 보너스를 받습니다 | C3 | 퀘스트, 퀘스트 보너스 |
| 6 | 오후에 **티타임 라운지**로 가서 차를 마시고, 동료에게 칭찬을 보냅니다 | B3, B3-1 | 칭찬 받은 사람 |
| 7 | 회의 시간이 되면 **회의실**에 모입니다. 안건과 결과를 적고, 음성·화상은 외부 회의 링크로 엽니다 | B4 | |
| 8 | 지치면 **힐링 존(바닷가)**으로 달려가 쉽니다. 휴식 횟수가 쌓이고, 쌓인 만큼 업적이 열립니다 | B5 | |
| 9 | 퇴근할 때 오늘 한 일 요약을 보고 나갑니다 | C8 | |

게임형 화면이 부담스러우면 언제든 **단순하게 보기**(B7)로 바꿔 동료 목록과 상태만 볼 수 있습니다.

표의 공간·퀘스트·칭찬·아침 요약은 기능 모듈이라 팀이 끌 수 있습니다. 끈 팀에서는 그 단계가 빠지고, 업무·할 일·리포트·출석 흐름은 그대로입니다([README의 기능 구성](README.md#기능-구성-확정)).

## 관리자의 하루

1. 관리자 첫 화면에서 승인 대기 수와 오늘 출석 현황을 봅니다. ⟶ E1
2. 가입 요청을 승인하거나 거절합니다. ⟶ E2
3. 필요하면 구성원 역할을 바꾸거나 팀에서 내보냅니다. ⟶ E3
4. 이상한 변경이 있으면 활동 기록을 찾아봅니다. ⟶ E5

## 상태 규칙

| 상태 | 표시 | 언제 |
| --- | --- | --- |
| 한가함 | ● | 기본값 |
| 집중 중 | ◐ | 직접 설정 |
| 회의 중 | ◆ | 회의실에 들어가면 자동. 나오면 이전 상태로 |
| 자리 비움 | ○ | 직접 설정하거나 일정 시간 활동이 없을 때 |

힐링 존에 있을 때의 상태는 정하지 못한 점 #4입니다.

## 예외 흐름

- **승인이 거절됨**: A2 거절 상태에서 다른 팀에 다시 요청할 수 있습니다.
- **퇴근 요약을 안 보고 창을 닫음**: 마지막 활동 시각을 퇴근 시각으로 씁니다 (정하지 못한 점 #10).
- **같은 사람이 여러 탭·기기로 접속**: 공간에는 한 명으로 보이고, 가장 최근에 움직인 탭의 위치를 따릅니다.
- **접속이 끊김**: 잠시 기다렸다가 다시 연결되지 않으면 공간에서 사라집니다. 다른 사람에게는 "○○님이 나갔어요"가 뜨지 않고 조용히 사라집니다.
