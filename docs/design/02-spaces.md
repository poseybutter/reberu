# 공간 목록과 공간별 행동

## 공간 목록

팀마다 여섯 공간이 있습니다. 사용자는 한 번에 한 공간에 있고, 공간 안에서는 걸어 다닙니다.

| 공간 | 하는 일 | 화면 |
| --- | --- | --- |
| 로비 | 출석 기록, 인사 | B1 |
| 내 자리 | 오늘의 퀘스트·업무 확인, 상태 바꾸기 | B2 |
| 티타임 라운지 | 차 마시기, 칭찬 보내기, 가벼운 채팅 | B3 |
| 회의실 | 안건·메모·결과 기록, 외부 회의 열기 | B4 |
| 힐링 존: 바닷가 | 불멍·물멍·요가, 휴식 횟수 쌓기 | B5 |
| 힐링 존: 산길 | 걷기, 걷멍·산멍, 함께 걸은 거리 쌓기 | B12 |

공간 사이 이동은 위쪽의 공간 목록 버튼이나 미니맵(B6)으로 합니다. 업무 행동은 공간을 옮기지 않아도 업무 패널에서 할 수 있습니다([README의 화면 방향](README.md#화면-방향-확정)).

## 공간 안에서 걷기와 자리

공간 안은 걸어 다니고, 공간 사이는 골라서 바로 옮깁니다([README의 이동 방식](README.md#이동-방식-공간-사이는-고르고-공간-안은-걷기)).

| 공간 | 앉을 수 있는 자리 | 3D 세기 |
| --- | --- | --- |
| 로비 | 없음 (서서 인사) | 중 |
| 내 자리 | 책상 (구성원마다 하나) | 약 |
| 티타임 라운지 | 테이블 둘레 의자 | 중 |
| 회의실 | 회의 테이블 의자 | 약 |
| 힐링 존: 바닷가 | 통나무 의자, 돗자리, 비치 의자, 요가 매트 | 강 |
| 힐링 존: 산길 | 나무 의자, 바위 쉼터, 쉼터 벤치, 전망대 | 강 |

- 공간마다 정원이 있습니다. 정원은 팀 설정으로 정하며, 기본값은 아직 정하지 않았습니다.
- 정원이 차면 들어갈 수 없고 "자리가 다 찼어요"를 보여 줍니다. 이때도 업무 패널은 그대로 쓸 수 있습니다.
- 자리 가까이 가면 "앉기" 버튼이 뜹니다. 공간별 행동(차 마시기, 휴식 시작 등)도 해당 소품 가까이에서 뜹니다.
- 위치는 같은 공간에 있는 사람끼리만 주고받습니다.

## 공통 화면 요소

모든 공간 화면(B1~B5)에 들어갑니다.

| 요소 | 내용 |
| --- | --- |
| 업무 패널 | 내 상태, 오늘 할 업무, 오늘의 퀘스트, 알림 바로가기. 어느 공간에서나 같은 자리에 고정 |
| 위쪽 막대 | 팀 이름(누르면 팀 바꾸기), 현재 시각, 접속자 수, 내 레벨·EXP 막대, 알림, 설정 |
| 공간 목록 버튼 | 로비 / 내 자리 / 라운지 / 회의실 / 힐링 존. 지금 있는 곳 표시 |
| 아래쪽 행동 막대 | 공간마다 다른 행동 버튼 |
| 아바타 | 원 + 이름표 + 상태 표시 |
| 잠깐 뜨는 알림 | 화면 오른쪽 아래에 몇 초 떴다 사라짐. 예: "하늘님이 출근했어요" |
| 보기 전환 | 게임형 화면 ↔ 단순하게 보기(B7) |

## 공간별 행동

### 로비 (B1)

| 행동 | 결과 |
| --- | --- |
| 들어오기 | 출석은 팀을 연 순간 이미 기록됨([출석 규칙](03-progression.md#출석-규칙-고정)). 로비는 출석 장면(도장, 연속 출석, 받은 EXP)을 보여 주고, 동료에게 "○○님이 출근했어요" |
| 인사하기 | 로비에 있는 동료에게 "○○님이 인사했어요" |
| 아바타 누르기 | 동료 카드(B8) |

### 내 자리 (B2)

아래 행동 가운데 상태 바꾸기, 퀘스트 체크, 업무 상태 바꾸기는 업무 패널에서 어디서나 할 수 있습니다. 내 자리는 집중하러 가는 공간입니다(정하지 못한 점 #3).

| 행동 | 결과 |
| --- | --- |
| 상태 바꾸기 | 모든 동료 화면에서 내 상태 표시가 바뀜 |
| 퀘스트 체크 | EXP 지급. 모두 끝내면 보너스 |
| 업무 상태 바꾸기 | 업무 목록 갱신. 완료하면 EXP |
| 업무 열기 | 업무 상세(C2) |

### 티타임 라운지 (B3)

| 행동 | 결과 |
| --- | --- |
| 차 마시기 | 라운지에 있는 동료에게 "○○님이 차를 마셔요" |
| 칭찬 보내기 | 칭찬 창(B3-1). 보내면 받는 사람이 EXP를 받고 알림을 받음 |
| 채팅 | 라운지에 있는 사람끼리 짧은 메시지 |
| 리액션 | 라운지에 있는 사람에게 짧은 반응 |

### 회의실 (B4)

| 행동 | 결과 |
| --- | --- |
| 들어가기 | 상태가 "회의 중"으로 바뀜. 참석자 목록에 추가 |
| 안건 적기 | 회의 전에 안건 목록 작성 |
| 회의 시작 | 회의 중 상태. 참석자에게 "회의가 시작됐어요" |
| 외부 회의 열기 | 등록된 외부 회의 링크를 새 창으로 엶 |
| 메모 쓰기 | 참석자 모두가 같은 메모를 봄 |
| 회의 끝내기 | 결과 요약 화면. 참석자 모두에게 결과가 보임 |

### 힐링 존 (B5)

바닷가에 쉬는 자리가 네 종류 있습니다. 어느 자리에서든 "멍하기"나 "요가"를 시작하면 휴식으로 셉니다.

| 쉬는 자리 | 모습 | 쉬는 방법 |
| --- | --- | --- |
| 모닥불 | 모래 위 모닥불과 둘레의 통나무 의자 | **불멍**: 불꽃이 천천히 흔들리고 가끔 불티가 오름 |
| 파도 앞 돗자리 | 물가에 깔린 돗자리 | **물멍**: 파도가 천천히 밀려왔다 빠짐 |
| 파라솔 | 파라솔 그늘과 비치 의자 | **물멍**: 그늘에서 먼바다를 봄 |
| 요가 매트 | 바다를 향해 나란히 깔린 요가 매트 | **요가**: 짧은 동작(숨 고르기, 기지개, 앉은 자세, 비틀기)을 골라 아바타가 천천히 따라 함. 화면에 들숨·날숨 안내가 느리게 나옴 |

| 행동 | 결과 |
| --- | --- |
| 자리 가까이 → 앉기 | 그 자리에 앉음 |
| 멍하기 시작 | 휴식 타이머 시작. 카메라가 천천히 불이나 바다 쪽으로 다가가고, 업무 패널과 위쪽 막대가 접혀 화면 가장자리에 작게 남음. 소리를 켜 두었으면 불 타는 소리나 파도 소리 |
| 멍하는 동안 | 받은 알림은 모아 두고 띄우지 않음(제안 #5). 업무 패널은 언제든 다시 펼칠 수 있음 |
| 요가 동작 고르기 (요가 매트) | 동작 버튼을 누르면 아바타가 그 동작을 천천히 함. 옆 매트 사람에게도 보임. 동작은 기록하지 않고 요가 시간만 휴식으로 셈 |
| 장작 넣기 (모닥불) | 모닥불 둘레 사람에게 "다온님이 장작을 넣었어요". 둘레에 앉은 사람이 많을수록 불이 조금 커짐. 기록하지 않음 |
| 멍하기 끝 | 휴식 횟수 +1, 불멍·물멍·요가 횟수도 따로 셈. 모아 둔 알림을 한 번에 보여 줌. 기준을 넘으면 업적이 열림 |

- 바다와 하늘은 조직 시간대의 지금 시각을 따릅니다. 낮에는 밝은 바다, 저녁에는 노을, 밤에는 어두운 바다와 모닥불 빛이 보입니다. 변화는 아주 느리게 합니다.
- 모닥불은 밤에 더 밝게 보이지만 낮에도 쓸 수 있습니다.
- 자리 수가 곧 힐링 존의 정원입니다(모닥불 의자 + 돗자리 + 파라솔 의자 + 요가 매트).

#### 날씨

바닷가에는 날씨가 있습니다. 실제 날씨가 아니라 서버가 정하는 **가상 날씨**이고, 같은 조직의 모든 사람이 같은 날씨를 봅니다.

| 날씨 | 바닷가 모습 | 쉬는 자리에 주는 변화 |
| --- | --- | --- |
| 맑음 | 밝은 바다, 잔잔한 파도 | 없음 |
| 구름 조금 | 구름 그림자가 천천히 지나감 | 없음 |
| 흐림 | 회색 하늘, 조금 높은 파도 | 없음 |
| 비 | 가는 빗줄기, 모래에 빗자국 | 모닥불이 작아지지만 꺼지지 않음. 파라솔 아래에서 빗소리 |
| 바람 | 파라솔이 흔들리고 모래가 날림 | 모닥불 불꽃이 한쪽으로 기움 |
| 안개 | 먼바다가 흐려짐 | 물멍 화면이 더 고요해짐 |
| 눈 (겨울만) | 모래 위에 얇게 쌓이는 눈 | 모닥불 둘레가 더 밝아 보임 |
| 무지개 (비 갠 뒤 드물게) | 바다 위 무지개 | 처음 본 사람에게 업적 |

- 서버가 하루에 몇 번 날씨를 바꿉니다. 바뀔 때는 몇 분에 걸쳐 천천히 바꿉니다. 계절(조직 시간대 기준 달)에 따라 나올 수 있는 날씨가 다릅니다.
- 시간대(낮·노을·밤)와 날씨는 함께 적용됩니다. 예: 비 오는 밤, 안개 낀 노을.
- **천둥·번개처럼 번쩍이는 효과는 쓰지 않습니다**(README 원칙 4).
- 날씨 효과(비·눈 입자)는 설정에서 끌 수 있습니다. 끄면 하늘색만 바뀝니다. 기기가 느리면 자동으로 줄입니다.
- 같은 날씨가 로비 창밖, 연회장 큰 창 밖에도 보입니다.

### 힐링 존: 산길 (B12)

바닷가 옆 산으로 이어지는 **걷는 길**입니다. 순례길처럼 천천히 걸으며 길 위의 풍경과 쉼터를 지나고, 정상에 오르면 바닷가가 내려다보입니다. 온라인 순례길 레퍼런스의 "길을 따라 걷기, 길 위에 말 남기기, 도장 모으기" 아이디어를 가져오되, 길 모양·표지·문구는 reberu에 맞게 새로 만듭니다.

**길의 구간** (아래에서 위로, 한 바퀴 돌아 내려옴)

| 구간 | 모습 | 쉬는 곳 |
| --- | --- | --- |
| 숲 입구 | 바닷가에서 이어지는 오솔길, 나무 이정표 | 길 안내판 (오늘 팀이 함께 걸은 거리) |
| 숲길 | 키 큰 나무 사이로 빛이 드는 길 | 나무 의자 |
| 계곡 | 돌다리와 작은 폭포 | 바위 쉼터 (**물멍**) |
| 오르막 쉼터 | 지붕 있는 작은 쉼터 | 쉼터 벤치, 말 남기기 |
| 정상 전망대 | 탁 트인 능선, 아래로 바닷가와 사무실이 보임 | 전망대 (**산멍**) |
| 내려오는 길 | 들꽃 핀 비탈길, 입구로 돌아옴 | 없음 |

**행동**

| 행동 | 결과 |
| --- | --- |
| 걷기 | 직접 걸어서 길을 따라 오름 |
| 천천히 걷기 (자동) | 버튼을 누르면 아바타가 길을 따라 혼자 천천히 걷고 카메라가 뒤에서 따라감. 업무 패널과 위쪽 막대가 접힘(**걷멍**). 아무 키나 누르면 멈춤 |
| 쉬는 곳에 앉기 | 바위 쉼터는 물멍, 전망대는 산멍을 시작. 바닷가와 같은 규칙(알림 모으기, 패널 접기) |
| 구간 도장 | 구간에 처음 닿으면 그 구간의 작은 도장을 받음. 한 바퀴의 도장을 모두 모으면 "한 바퀴 완주" |
| 말 남기기 (오르막 쉼터) | 짧은 말을 남기면 그 자리에 작은 돌탑(쪽지)이 쌓임. 같은 팀 사람만 읽음 (정하지 못한 점 #29) |
| 인사하기 | 길에서 마주친 동료에게 짧은 인사 |
| 걷기 끝 | 걸은 거리와 시간을 휴식으로 셈. 모아 둔 알림을 한 번에 보여 줌 |

- **팀이 함께 걸은 거리**가 쌓입니다. 숲 입구 안내판에 오늘과 이번 시즌의 팀 거리가 보이고, 일정 거리마다 길가에 새 풍경(꽃밭, 작은 정자 등)이 열립니다. 경쟁이 아니라 함께 쌓는 기록입니다.
- **계절**이 산을 바꿉니다(조직 시간대 기준 달): 봄 꽃, 여름 짙은 초록, 가을 단풍, 겨울 눈 덮인 길. 날씨는 바닷가와 같고, 안개 낀 날은 정상 아래로 구름바다가 깔립니다.
- 시간대(낮·노을·밤)도 바닷가와 같습니다. 밤에는 길가에 작은 등이 켜집니다.
- 정원은 쉬는 곳 자리 수가 아니라 길 위에 동시에 있을 수 있는 사람 수로 정합니다. 기본값은 정하지 않았습니다.
- 바닷가에서 숲 입구로 걸어가거나, 공간 목록에서 산길을 골라 바로 갈 수 있습니다. 바닷가와 산길은 길로 이어져 있지만 서로 다른 공간입니다.

## 조직 공간 [모듈: 조직 공간]

팀 공간과 따로, **조직 전체가 함께 들어오는 공간**입니다. 전체 모임(연회장)이나 다른 팀과의 회의를 여기서 합니다. 조직 관리자가 F4에서 켜는 **조직 단위 모듈**이며, 팀마다 켜고 끄지 않습니다([06-multi-team.md](06-multi-team.md#조직-소속-데이터)).

| 공간 | 하는 일 | 화면 | 3D 세기 | 정원 |
| --- | --- | --- | --- | --- |
| 광장 | 다른 팀 사람과 오가며 인사, 연회장·공용 회의실 입구 | B9 | 중 | 조직 설정 (기본값 정하지 않음) |
| 연회장 | 조직 전체 모임(타운홀 미팅). 팀별 긴 테이블과 앞쪽 단상 | B10 | 중 | 조직 설정 |
| 공용 회의실 | 여러 팀이 함께하는 회의 | B11 | 약 | 방마다 정함 |

- 위쪽 공간 목록에 "조직 공간"이 따로 묶여 보입니다. 팀 공간과 조직 공간 사이도 골라서 바로 옮깁니다.
- 조직 공간에 있는 동안에도 업무 패널은 **지금 보고 있는 팀**의 것입니다. 출석은 팀 규칙 그대로입니다(그 팀을 연 순간).
- 조직 공간에 있으면 팀 동료에게 "다온님은 연회장에 있어요"처럼 위치가 보입니다.
- 조직 공간의 아바타는 계정의 기본 아바타를 씁니다. 팀별 꾸미기는 팀 공간에서만 보입니다.

### 연회장 (B10)

조직 전체가 모이는 큰 홀입니다. 타운홀 미팅, 시즌 마감 시상, 새 구성원 환영 같은 전체 모임을 합니다.

**배치**
- 홀 가운데에 **팀마다 긴 테이블**이 하나씩 놓입니다. 테이블 끝에 팀 이름표가 있고, 들어가면 내 팀 테이블의 빈자리에 앉습니다. 다른 팀 테이블에도 빈자리가 있으면 옮겨 앉을 수 있습니다.
- 앞쪽에는 테이블과 수직으로 놓인 **단상**이 있습니다. 진행자와 발표자가 단상에 섭니다.
- 팀 수가 늘면 테이블이 옆으로 늘어나고, 팀이 많으면 두 줄로 놓습니다. 테이블 배치는 팀 목록에서 자동으로 정합니다.
- 분위기는 reberu의 바닷가 콘셉트로 새로 만듭니다. 예: 높은 천장, 바다 노을이 보이는 큰 창, 천장에 매달린 등, 나무 긴 테이블. 특정 영화나 작품의 연회장(문장, 깃발, 떠 있는 촛불, 하늘이 비치는 천장 등)을 따라 하지 않습니다.

| 행동 | 결과 |
| --- | --- |
| 들어가기 | 내 팀 테이블 빈자리에 앉음. 모임 중이면 내 상태가 "회의 중"으로 바뀜 |
| 진행자가 시작 | 조직 전체에 "전체 모임이 시작됐어요" 알림 (D2에서 끌 수 있음) |
| 단상에 오르기 | 진행자와 진행자가 부른 발표자만. 단상에 선 사람이 모두에게 크게 보임 |
| 순서 넘기기 | 진행자가 안건 순서를 넘기면 모두의 화면에 지금 안건이 바뀜 |
| 손들기 | 진행자에게 손든 사람 목록이 보임. 진행자가 부르면 단상으로 |
| 질문 남기기 | 질문 목록에 추가. 다른 사람이 "나도 궁금해요"로 올림. 이름을 숨기고 남길 수 있음 |
| 리액션 | 테이블 위에 짧게 떴다 사라짐. 많이 모이면 하나로 묶어 "👏 32"처럼 보임 |
| 외부 회의 열기 | 음성·화상은 외부 링크로 엶 |
| 진행자가 끝내기 | 요약(안건, 답한 질문, 남은 질문)을 조직 전체가 봄 |
| 건배 | 모임이 끝난 뒤나 시상 때 진행자가 "건배"를 누르면 모든 테이블에서 잔을 드는 짧은 연출. 업무를 막지 않음 |

### 공용 회의실 (B11)

팀 회의실(B4)과 같은 행동을 합니다. 다른 점은 아래와 같습니다.

- 회의를 연 사람이 **참석자를 여러 팀에서 고릅니다.** 고른 사람만 들어올 수 있습니다.
- 회의 기록은 어느 팀에도 속하지 않고 조직에 속합니다. 참석자와 조직 관리자만 봅니다.
- 회의에서 나온 할 일은 각자 자기 팀의 업무로 만듭니다. 공용 회의실에서 다른 팀 업무를 직접 만들지 않습니다.
