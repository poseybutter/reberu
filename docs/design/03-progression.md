# 출석, EXP, 오늘의 퀘스트, 레벨업, 업적, 명예의 전당

## 출석 규칙 (고정)

| 항목 | 규칙 |
| --- | --- |
| 기록하는 때 | 근무일에 **그 팀을 처음 연 순간** 자동으로 기록합니다. 어느 화면으로 들어왔는지(로비, 업무 화면, 알림 링크)는 상관없습니다. "출근하기" 버튼은 없습니다 |
| 팀이 여럿일 때 | 팀마다 따로 기록합니다. 실제로 연 팀만 기록됩니다 |
| 근무일 | 월~금 가운데 **조직 휴일 달력에 없는 날**. 주말과 공휴일은 근무일이 아닙니다 |
| 하루의 경계 | 조직 시간대의 **자정**. 시간대는 조직 설정(F7)에서 정합니다 |
| 근무일이 아닌 날 들어오면 | 접속한 기록만 남깁니다. 출석 EXP를 주지 않고, 연속 출석에도 넣지 않습니다. 연속 출석이 끊기지도 않습니다 |
| 연속 출석 | 근무일만 셉니다. 금요일에 출석하고 다음 근무일(월요일 등)에 출석하면 이어집니다. 근무일에 출석하지 않으면 끊깁니다 |
| 지각 | 판정하지 않습니다. 출석 시각만 남기고, 리포트와 퇴근 요약에 보여 줍니다 |
| 조직 관리자 | 팀 구성원이 아니면 출석을 기록하지 않습니다 |

- 공휴일은 조직 관리자가 조직 휴일 달력(F8)에 넣습니다. 외부 공휴일 서비스는 쓰지 않습니다.
- 휴일 달력을 나중에 고쳐도 이미 남은 출석 기록은 바꾸지 않습니다. 연속 출석은 바뀐 달력으로 다시 셉니다.
- 개인 휴가 중에 연속 출석이 끊기는 문제는 정하지 못한 점 #24입니다.

## EXP를 얻는 곳

| 출처 | EXP (초안) | 화면 | 기능 |
| --- | --- | --- | --- |
| 출석 (근무일만) | 10 | B1 | 고정 |
| 연속 출석 (근무일 기준) | 3일째 +5, 5일째 +20, 20일째 +100 | B1 | 고정 |
| 업무 완료 | 낮음·보통 10, 높음 15, 긴급 20 | C1, C2 | 고정 |
| 오늘의 할 일 하나 | 2 (하루 10개까지) | C3 | 고정 |
| 오늘의 퀘스트 하나 | 5 | C3 | 모듈: 오늘의 퀘스트 |
| 오늘의 퀘스트 모두 완료 보너스 | 15 | C3 | 모듈: 오늘의 퀘스트 |
| 칭찬 받기 | 5 | B3-1, B8 | 모듈: 칭찬 |

- 수치는 초안입니다. 운영하면서 조정합니다.
- 완료를 풀면 받은 EXP를 돌려받고, 다시 완료하면 다시 받습니다. 한 업무로 받는 EXP는 한 번 몫을 넘지 않습니다(정하지 못한 점 #19). 할 일도 같습니다.
- 할 일은 직접 적고 직접 체크하므로 EXP를 작게 주고 하루 상한을 둡니다.
- 자기 자신에게는 칭찬을 보낼 수 없습니다.
- 모듈을 끄면 그 모듈의 EXP 출처도 사라집니다. 이미 받은 EXP는 그대로입니다.
- 조직 모듈도 EXP 출처를 더할 수 있습니다([README의 기능 구성](README.md#기능-구성-확정)).
- 하루 전체 상한은 제안 #6입니다.

## 오늘의 할 일과 오늘의 퀘스트 (C3)

| 구분 | 누가 정하나 | 체크 | 기능 |
| --- | --- | --- | --- |
| 오늘의 할 일 | 구성원이 직접 적음 | 직접 체크 | 고정 |
| 오늘의 퀘스트 | 서버가 공통 목록에서 매일 3개를 뽑음 | 행동하면 자동 체크 | 모듈 |

- 퀘스트 예시: "동료 한 명에게 인사하기", "업무 하나 완료하기", "힐링 존에서 한 번 쉬기". 행동으로 확인되는 것만 둡니다.
- 켜지 않은 모듈과 관련된 퀘스트(예: 공간을 끈 팀의 "힐링 존에서 쉬기")는 뽑지 않습니다.
- 이 나눔은 가정입니다(정하지 못한 점 #1, #2).

## 시즌

- 시즌은 모든 팀이 같은 규칙을 씁니다(고정 기능). 길이는 초안으로 한 달입니다.
- 누적 EXP와 레벨은 시즌이 바뀌어도 그대로이고, 시즌 EXP만 새로 시작합니다.
- 시즌이 끝나면 그 시즌의 순위와 특별상(가장 오래 연속 출석한 사람 등)을 기록으로 남깁니다. 명예의 전당 모듈을 켠 팀은 C6에서 봅니다.

## 레벨

| 레벨 | 필요한 누적 EXP |
| --- | --- |
| 2 | 100 |
| 3 | 250 |
| 5 | 700 |
| 10 | 2,700 |
| 20 | 10,450 |

- 공식 초안: 레벨 n까지 필요한 누적 EXP = `25 × (n - 1) × (n + 2)`
- 레벨은 내려가지 않습니다.

## 레벨업 연출 (C4)

1. EXP를 받는 순간 `+10 EXP`가 떠오르고 위쪽 EXP 막대가 찹니다.
2. 레벨이 오르면 먼저 짧은 알림 "Lv.5가 됐어요"가 뜹니다. 하던 일을 가리지 않습니다. 알림을 누르면 축하 창(새 레벨, 새로 열린 것)이 열립니다.
3. 같은 공간의 동료에게 잠깐 뜨는 알림 "○○님이 Lv.5가 됐어요".

## 레벨로 열리는 것

| 종류 | 예시 |
| --- | --- |
| 칭호 | 이름표 옆에 붙는 짧은 칭호. 문구는 새로 지음 |
| 아바타 꾸미기 | 아바타 테두리 모양, 이름표 모양 |
| 책상 꾸미기 | 내 자리의 소품 상자 (`[화분]`, `[머그컵]`, `[스탠드]`) |
| 공간 | 힐링 존의 새 구역 (예: 바닷가 옆 숲길) |

어느 레벨에 무엇을 여는지는 도메인 모델 단계에서 정합니다.

## 휴식 기록

- 휴식은 바닷가(불멍, 물멍, 요가)와 산길(걷멍, 물멍, 산멍)에서 셉니다. 종류마다 횟수와 시간을 따로 남깁니다.
- 휴식은 EXP를 주지 않습니다. 쉬는 것까지 점수가 되면 쉼이 일이 되기 때문입니다. 대신 업적과 꾸미기로 보여 줍니다.
- 산길에서 걸은 거리는 사람마다 남기고, 팀이 함께 걸은 거리로도 더합니다. 팀 거리는 시즌마다 새로 시작하고, 일정 거리마다 산길에 새 풍경이 열립니다(팀 공동 기록, 순위 없음).

## 출석 도장판 (C5)

근무일에 출석하면 도장이 하나 찍히는 달력 모양으로 보여 줍니다. 주말과 공휴일 칸은 흐리게 두어 비어 있어도 끊긴 것처럼 보이지 않게 하고, 연속 출석은 이어진 도장으로 보입니다. 온라인 순례길의 도장 모으기에서 가져온 방식입니다.

## 명예의 전당 (C6, 모듈)

| 순위 | 기준 |
| --- | --- |
| 시즌 EXP | 이번 시즌에 얻은 EXP 합계 |
| 연속 출석 | 지금 이어지고 있는 연속 출석 일수 |
| 칭찬 많이 받은 사람 | 이번 시즌에 받은 칭찬 수 (칭찬 모듈을 켠 팀만) |

순위가 부담이 될 수 있는 점은 정하지 못한 점 #5입니다. 명예의 전당은 모듈이라 팀이 끌 수 있습니다.
