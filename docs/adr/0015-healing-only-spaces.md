# ADR-0015. 공간에는 업무 기능을 두지 않음

> 버전: v0.1.0\
> 수정일: 2026-11-05

- 상태: Accepted
- 영향: [product/overview.md](../product/overview.md) §5.2, §7, [product/spaces.md](../product/spaces.md) UX-SPACE-07·33·52, [product/screens.md](../product/screens.md) B2·B4·B10, [product/flows.md](../product/flows.md) UX-FLOW-15

## 맥락

- [ADR-0001](0001-work-tool-first.md)은 업무 관리를 본체로, 공간을 그 위의 선택 계층으로 정했다. 업무 행동은 공간을 거치지 않고 어디서나 한다.
- 그런데 초기 설계는 공간 안에 업무 기능을 두었다. 내 자리의 집중 시작, 회의실의 안건·메모·결과, 연회장의 진행자·단상·질문, 여러 팀이 함께 쓰는 공용 회의실(B11)과 연회장 모임 관리(F9)가 그것이다.
- 공간에 업무 기능이 있으면 세 가지 문제가 생긴다.
  - 공간 모듈을 끈 팀이나 단순하게 보기(B7)에서 그 기능을 쓸 수 없다. ADR-0001의 "공간에서만 되는 업무 기능은 만들지 않는다"와 어긋난다.
  - 회의 기록 같은 업무 데이터가 공간 모듈에 속하게 된다. 모듈을 끄면 업무 데이터가 사라지거나, 고정 기능이 모듈에 기대게 된다([ADR-0014](0014-module-architecture.md)의 의존 방향과 어긋난다).
  - 정해야 할 것이 크게 늘어난다. 집중 시작의 역할(OQ-03), 회의를 누가 여는가(OQ-07), 메모 동시 수정(OQ-08), 모임을 누가 여는가(OQ-20), 회의 기록의 소속(OQ-42)이 모두 여기서 나왔다.

## 결정

- 공간은 일하다 쉬러 가는 휴식·교류의 층이다. 공간에는 업무 기능을 두지 않는다(UX-SPACE-07).
- 공간에서 하는 행동은 기록이 남더라도 업무 데이터(업무, 할 일, 리포트, 회의 기록)를 만들지 않는다.
- 업무 정보를 읽기만 하는 오브제(예: 회의실 현황판)는 업무 기능이 아니므로 둘 수 있다. 오브제는 업무 데이터를 고치지 않고, 업무 행동은 공간 밖 화면으로 연결한다. 오브제가 없어도(공간 모듈 꺼짐, B7) 같은 정보를 업무 패널과 C 화면에서 볼 수 있어야 한다.
- 공간마다 남기는 행동은 다음뿐이다.

| 공간 | 남기는 행동 | 뺀 기능 |
| --- | --- | --- |
| 내 자리(B2) | 책상에 앉기, 레벨로 연 소품으로 책상 꾸미기 | 집중 시작 |
| 회의실(B4) | 모여 앉기, 팀 설정에 등록한 외부 회의 링크 열기 | 안건, 메모, 결과 요약, 회의 열기·시작·끝내기 |
| 연회장(B10) | 앉기, 자리 옮기기, 리액션, 건배 | 진행자, 단상, 안건, 손들기, 질문, 모임 요약 |
| 공용 회의실(B11) | 화면 자체를 없앤다 | 여러 팀 회의와 조직 소속 회의 기록 |
| 연회장 모임 관리(F9) | 화면 자체를 없앤다 | 모임 만들기와 진행자 지정 |

- 공간에 들어가거나 나가도 현재 상태(`AVAILABLE`, `FOCUS`, `MEETING`)는 바뀌지 않는다. 현재 상태는 사용자가 직접 고른다(UX-FLOW-15).
- 음성·화상 회의는 직접 만들지 않고 외부 회의 링크로 대신한다. 공간 안 음성·화상 회의는 후보 기능으로만 둔다([product/overview.md](../product/overview.md) §7).

## 검토한 대안

| 대안 | 버린 이유 |
| --- | --- |
| 회의 기록을 공간 모듈에 둔다 | 공간 모듈을 끄면 회의 기록을 쓸 수 없고, B7에서도 쓸 수 없다 |
| 회의 기록을 고정 기능으로 만들고 회의실에서도 열게 한다 | 지금 범위에서 회의 기록은 업무 기능의 핵심이 아니다. 필요해지면 공간과 무관한 별도 모듈로 만든다 |
| 연회장 진행 기능(진행자, 질문)을 둔다 | 조직 전체 행사를 진행하는 도구가 되어 휴식 공간의 성격과 맞지 않고, 권한·소속 규칙이 크게 늘어난다 |

## 결과

- 좋아지는 점: 공간 모듈을 끄거나 B7로 봐도 잃는 업무 기능이 없다. 공간 모듈이 업무 데이터를 갖지 않아 끄고 켜기가 단순하다. 미결 사항 OQ-03·07·08·20·42가 사라진다.
- 감수하는 점: 회의 기록과 조직 행사 진행 기능이 없다. 필요한 팀은 외부 도구를 쓴다.
- 후속 작업: 회의 기록이 필요해지면 공간과 무관한 모듈로 설계하고 새 ADR을 쓴다.
