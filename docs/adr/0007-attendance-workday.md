# ADR-0007. 출석: 근무일과 자정 경계

> 버전: v0.1.0\
> 수정일: 2026-11-04

- 상태: Accepted
- 영향: [domain/rules.md](../domain/rules.md) 출석 절, [product/screens.md](../product/screens.md) B1·C5·F7·F8

## 맥락

- 처음에는 "로비에 들어온 순간" 출석을 기록하려 했다. 공간은 끌 수 있는 모듈이므로 공간을 끈 팀은 출석이 안 된다. 알림 링크로 업무 화면에 바로 들어와도 출석이 되어야 한다.
- "출근하기" 버튼은 누르는 것을 잊으면 출석이 빠진다.
- 출석은 평일 기준이어야 한다. 주말·공휴일에 들어와도 출석으로 세면 쉬는 날 출근을 부추긴다.
- 출석과 연속 출석이 평가 도구가 되면 안 된다.

## 결정

- 근무일에 **그 팀을 처음 연 순간** 서버가 자동으로 출석을 기록한다. 어느 화면으로 들어왔는지는 상관없다. "출근하기" 버튼은 없다.
- 근무일은 월~금 가운데 조직 휴일 달력에 없는 날이다. 공휴일은 조직 관리자가 휴일 달력에 넣는다. 외부 공휴일 서비스는 쓰지 않는다.
- 하루의 경계는 조직 시간대의 자정이다. 조직마다 시간대 하나, 휴일 달력 하나를 둔다.
- 근무일이 아닌 날 들어오면 접속 기록만 남긴다. 출석 EXP를 주지 않고 연속 출석에 넣지 않으며, 연속 출석을 끊지도 않는다.
- 연속 출석은 근무일만 센다.
- 지각을 판정하지 않는다. 출석 시각만 남긴다.
- 출석은 팀마다 따로 기록한다. 조직 관리자는 팀원이 아니면 출석을 남기지 않는다.

## 검토한 대안

| 대안 | 버린 이유 |
| --- | --- |
| 로비 입장 시 기록 | 공간을 끈 팀에서 출석이 안 된다 |
| "출근하기" 버튼 | 누르는 것을 잊으면 출석이 빠진다 |
| 모든 날을 출석 대상으로 | 쉬는 날 출근을 부추기고, 주말에 연속 출석이 끊긴다 |
| 하루 경계를 새벽 4시로 | 단순성이 떨어진다. 자정으로 정했다 |
| 외부 공휴일 API | 의존성과 장애 지점이 늘어난다 |

## 결과

- 좋아지는 점: 공간 유무와 관계없이 같은 규칙이 돈다. 쉬는 날을 존중한다.
- 감수하는 점: 조직 관리자가 휴일을 해마다 넣어야 한다. 개인 휴가 중에는 연속 출석이 끊긴다(OQ-18).
- 후속 작업: 휴일 달력을 고쳤을 때의 연속 출석 재계산 규칙을 [domain/rules.md](../domain/rules.md)에 둔다.
