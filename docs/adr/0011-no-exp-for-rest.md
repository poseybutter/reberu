# ADR-0011. 휴식에 EXP를 주지 않음

> 버전: v0.1.0\
> 수정일: 2026-11-04

- 상태: Accepted
- 영향: [domain/rules.md](../domain/rules.md) EXP·휴식 절, [product/spaces.md](../product/spaces.md) 힐링 존

## 맥락

- 힐링 존(바닷가, 산길)에서 불멍·물멍·요가·걷멍·산멍을 하면 휴식 기록이 쌓인다.
- 휴식에 EXP를 주면 쉬는 것이 점수 쌓기가 되어, 쉬는 시간이 또 하나의 일이 된다. 반복으로 EXP를 쌓는 남용도 생긴다.

## 결정

- 휴식에는 EXP를 주지 않는다.
- 휴식은 종류별 횟수와 시간으로만 남기고, 업적과 꾸미기로 보여 준다.
- 산길에서 걸은 거리는 사람마다 남기고 팀이 함께 걸은 거리로도 더한다. 팀 거리는 순위 없이 함께 쌓는 기록이다.

## 검토한 대안

| 대안 | 버린 이유 |
| --- | --- |
| 휴식 1회마다 작은 EXP | 쉬는 것이 점수가 되고, 반복 남용이 생긴다 |
| 휴식 시간 순위 | 쉬는 것까지 경쟁이 된다 |

## 결과

- 좋아지는 점: 힐링 존이 점수와 무관한 공간으로 남는다. EXP 남용 경로가 하나 준다.
- 감수하는 점: 휴식의 동기는 업적·꾸미기·분위기에만 기댄다.
- 후속 작업: 휴식 업적과 최소 휴식 시간 기준을 [domain/rules.md](../domain/rules.md)에 둔다.
